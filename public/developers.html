TMCast API

Pull live now-playing metadata or drop a self-updating player widget onto any site. Free, public, CORS-enabled — no key required.

Now Playing (JSON)

GET/api/np/:station

Use a station slug (e.g. one) or its id. Returns the current track, listener count, and links.

{
  "station": { "id": "…", "slug": "one", "name": "Mavion Radio One", "logo_url": "…" },
  "is_live": false,
  "listeners": 12,
  "now_playing": {
    "title": "Saturn", "artist": "SZA", "album": "SOS",
    "artwork_url": "https://…", "duration": 198, "elapsed": 64
  },
  "player_url": "https://cast.tmc.gg/player/one",
  "stream_url": "https://cast.tmc.gg/listen/one/radio.mp3"
}

Also available: /api/nowplaying (all public stations) and /api/nowplaying/:station (with request queue + recently played).

Embeddable player

A compact, auto-updating "now playing" card that opens the full player when clicked. Paste this anywhere:

<iframe src="https://cast.tmc.gg/embed/one"
  width="380" height="88" frameborder="0"></iframe>

Themes: add ?theme=dark or ?theme=transparent.

Embeddable widgets

Four self-updating widgets. One line — no iframe to size, the loader injects it for you:

<script src="https://cast.tmc.gg/widget.js"
  data-station="one" data-type="nowplaying" data-theme="dark"></script>

data-type: nowplaying listeners history status · data-theme: dark light transparent · optional data-width / data-height.

Prefer a plain iframe? Each widget is also reachable directly at /widget/:type/:station.

Audio stream & directories

GET/listen/:station/radio.mp3

A standard Icecast-style MP3 stream — drop it into any <audio> tag, VLC, foobar2000 or a hardware player.

<audio src="https://cast.tmc.gg/listen/one/radio.mp3" controls></audio>

Submitting to a directory (TuneIn, Radio Garden, a car stereo)? Use a playlist file instead:

https://cast.tmc.gg/listen/one/radio.m3u   # M3U — VLC, most players
https://cast.tmc.gg/listen/one/radio.pls   # PLS — TuneIn & directories
