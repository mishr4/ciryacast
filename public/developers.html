TMCast API

Pull live now-playing metadata or drop a self-updating player widget onto any site. Free, public, CORS-enabled — no key required.

Now Playing (JSON)

GET/api/np/:station

Use a station slug (e.g. one) or its id. Returns the current track, listener count, and links.

{
  "station": { "id": "…", "slug": "one", "name": "Mavion Radio One", "logo_url": "…" },
  "is_live": false,
  "listeners": 12,
  "now_playing": {
    "title": "Saturn", "artist": "SZA", "album": "SOS",
    "artwork_url": "https://…", "duration": 198, "elapsed": 64
  },
  "player_url": "https://cast.tmc.gg/player/one",
  "stream_url": "https://cast.tmc.gg/listen/one/radio.mp3"
}

Also available: /api/nowplaying (all public stations) and /api/nowplaying/:station (with request queue + recently played).

Embed widget

A compact, auto-updating "now playing" card. Paste this anywhere:

<iframe src="https://cast.tmc.gg/embed/one"
  width="380" height="88" frameborder="0"></iframe>

Themes: add ?theme=dark or ?theme=transparent. Clicking the widget opens the full player.

Audio stream

GET/listen/:station/radio.mp3

A standard MP3 stream — drop it into any <audio> tag, VLC, or media player.

<audio src="https://cast.tmc.gg/listen/one/radio.mp3" controls></audio>
